# Test Plan – Demoblaze Demo Store

## 1. Project Overview
Manual testing of Demoblaze demo e‑commerce store, including registration, login, product selection, cart, and checkout.

## 2. Test Objectives
- Validate registration and login
- Verify product selection and cart functionality
- Validate checkout process
- Ensure all end-to-end flows work correctly

## 3. Scope

### In Scope
- Registration
- Login/Logout
- Browse and select products
- Add to cart
- Checkout


## 4. Test Approach
Manual testing based on predefined scenarios, test cases, and acceptance criteria.

## 5. Test Environment
- Demoblaze demo store
- Chrome browser

## 6. Test Data
- Test user accounts
- Demo products in catalog

## 7. Risks
- Unstable public demo environment
- Dynamic catalog updates

## 8. Roles & Responsibilities
- QA: test design, execution, reporting

## 9. Deliverables
- Test Scenarios
- Test Cases
- Test Summary Report
