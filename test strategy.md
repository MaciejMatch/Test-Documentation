# Test Strategy – Demoblaze Demo E‑Commerce

## 1. Objective
Define the overall approach for manual testing of the Demoblaze demo e‑commerce application.

## 2. Scope
The tested functionality includes:
- User registration
- User login
- Browsing product catalog
- Adding products to the cart
- Viewing cart contents
- Checkout process

## 3. Test Types
- Functional testing
- Integration testing
- End-to-End (E2E) testing
- Positive and negative testing
- UI testing

## 4. Test Level
- System testing

## 5. Approach
Testing will be performed manually using:
- Test Scenarios
- Test Cases
- Acceptance Criteria

## 6. Test Environment
- Demoblaze demo store (public)
- Chrome browser
- Windows/macOS

## 7. Entry Criteria
- Application is accessible and functional
- Test cases are prepared and reviewed

## 8. Exit Criteria
- All test cases executed
- No critical defects
- Test Summary Report completed

## 9. Deliverables
- Test Scenarios
- Acceptance Criteria
- Test Cases
- Test Summary Report
