# Test Documentation – Demoblaze Demo Store

This repository contains professional test documentation for the **Demoblaze demo e-commerce store** (https://www.demoblaze.com).  
It includes high-level QA artifacts such as **Test Strategy**, **Test Plan**, and **Test Summary Report**.

---

## 📝 Project Overview

**Objective:**  
Provide structured documentation demonstrating planning, strategy, and reporting for manual testing of an e-commerce application.

**Scope:**  
- Test Strategy: overall approach, test types, and test environment  
- Test Plan: scope, objectives, test approach, roles, and risks  
- Test Summary Report: execution results, quality assessment, and recommendations  

**Scope Note:**  
This documentation focuses on the main user-facing functionality of the Demoblaze demo store.
